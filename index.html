NLP pipeline that detects investment signals from Reddit sentiment. Scrapes r/WallStreetBets via the Reddit API, scores each post with FinBERT (a finance-trained transformer model), and compares sentiment scores against real 5-day stock returns via yfinance. Backtesting shows a statistically significant Spearman correlation of +0.14 (p<0.05) and a 61% win rate — beating the 50% random baseline. Results displayed in a live Streamlit dashboard with Plotly charts.
